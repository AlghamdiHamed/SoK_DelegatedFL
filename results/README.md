# Experimental results

## Processed results

The processed directory contains selected reference results
for Studies I and II, including correctness, privacy, resource
measurements, utility and work-evasion analysis.

## Supplementary results

The feasibility-budget directory contains the measured memory
budget grid, analytical predictions and crossover summaries.

The supplementary reconstruction directory contains numerical
audits of the original Study-I learning runs.

## Reproduction

Use a separate working copy when reproducing the experiments
to preserve the published reference results.

Raw run directories and complete orchestration logs are not
included. The experiment runner generates these files during
reproduction.

The published results should not be overwritten.
